# Battle prototype — Sara vs Mike

Portrait mobile PvP battle screen. Open `index.html` in a browser, or publish with GitHub Pages.

## GitHub Pages (public link for a reviewer)

1. Create a GitHub account if you do not have one.
2. New repository, public, no README.
3. Upload this whole folder (`index.html` + `assets/`) as the repo root.
4. Settings → Pages → Deploy from branch → `main` / `/ (root)` → Save.
5. After a minute the link is:
   `https://YOUR_USERNAME.github.io/REPO_NAME/`

Do not send a Git password or personal token in chat.
